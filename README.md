# Навье–Стокс (задача Института Клэя): два пути, одна конструкция

Этот репозиторий — полная лаборатория по задаче тысячелетия
[«Existence and smoothness of the Navier–Stokes equation»](https://www.claymath.org/millennium-problems/navier-stokes-equation)
(формулировка Феффермана, 2000). В ней сходятся **два независимых пути**,
которые были построены и сверены вычислительно:

| Путь | Суть | Инструмент |
|---|---|---|
| **I. Редукция P³ → 𝔰𝔬(3)** | Компактификация пространства состояний вихря: ℝP³ ≅ SO(3), уравнения Эйлера–Пуанкаре `dΩ/dt = Ω × (I⁻¹Ω) − νLΩ`, кососимметричность ⇒ нелинейность не растит норму | Препринт (LaTeX/PDF, 17 стр.) + `verify_so3.py` |
| **II. Прямой калькулятор** | Нативный 3D-решатель Тейлора–Грина в poler-engine (бездивергентная проекция Якоби, фикс-точка) против спектрального эталона машинной точности | `solvers/` + `verification/` |

Кросс-верификация дала вердикт: **пути ложатся друг на друга на трёх
уровнях из четырёх** — законы, траектории и структура дискретизационной
ошибки. Четвёртый уровень (машинно-проверяемые формальные доказательства)
честно не закрыт ни одним из путей.

---

## 1. Официальная формулировка (Фефферман)

Четыре утверждения: **(A)** глобальная гладкость в ℝ³, **(B)** на торе 𝕋³,
**(C)/(D)** контрпримеры с blow-up за конечное время. Единственный член,
блокирующий 3D, — растяжение вихря `(ω·∇)u`: в 2D он тождественно нулевой,
поэтому Ладыженская (1959) закрыла плоский случай полностью. Вся программа
Пути I — заменить континуум ℝ³ на компактную орбитную структуру, где
нелинейность становится вращением (структурой Ли), а не растяжением.

## 2. Путь I: редукция P³ → 𝔰𝔬(3)

**Файлы:** `paper/poler_p3_so3_navier_stokes.pdf` (17 стр., 30 закладок),
исходники `paper/latex/`.

Ключевые результаты препринта:

- **RP³ = SO(3)** через кватернионы (полное доказательство, §2);
- вариационный вывод **уравнений Эйлера–Пуанкаре** на 𝔰𝔬(3)* (§3);
- **Ли–Пуансон** с прямым доказательством тождества Якоби для скобки
  {F,G} = ⟨∇F, Ω × ∇G⟩ (§4);
- **инварианты**: Казимир ‖Ω‖², гамильтониан ℋ; диссипация
  `dℋ/dt = −ν⟨Ω, LΩ⟩ ≤ 0` — сертификат Ляпунова (§6);
- коммутационная тонкость `[L, I] = 0` с контрпримером (ℋ растёт при
  убывающем C) — честное исследование, где редукция перестаёт быть
  тривиальной;
- **квантователь МакВини** `Q(x) = 3x² − 2x³`, спектр {0, ½, 1}, острота
  константы 4: `4·(¼)² = ¼` (подтверждено калькулятором движка);
- граница Грёнуолла **139.626** — достигается точно (не slack-оценка);
- **главный результат**: на сферических coadjoint-орбитах 𝔰𝔬(3) blow-up
  невозможен; условная штрейн-теорема (аналог BKM/CKN) (§7);
- честные границы метода: сферические орбиты SO(3) без растяжения ≠
  полная 3D с растяжением (§8).

**Верификация:** `verification/verify_so3.py` — **23/23 PASS**
(RK4, порядок 4.96 по Ричардсону): дрейф Казимира 5.7·10⁻⁹, замкнутость
орбит Лиувилля 5·10⁻¹⁵, острота МакВини 0.999997, Грёнуолл = граница.

## 3. Путь II: прямой калькулятор

**Файлы:** `solvers/bench_navier_stokes_clay.rs` — нативный решатель
(дословно из `poler-engine-org/poler-engine`, `crates/pqc/examples/`),
`solvers/bench_navier_stokes_clay_max.rs` — параметрическая копия
(алгоритм бит-в-бит, параметры снаружи).

Решатель: вихрь Тейлора–Грина на сетке, центральные разности,
бездивергентная проекция Якоби (12 итераций), шаг Эйлера. Дословный
запуск (32³, T=0.4): `E(0) = 31.006277 = π³` — аналитически точно,
`E(0.4) = 30.642942`, `div = 9.51e-5`.

**Спектральный эталон** (`ns_spectral_reference.py`, `ns_spectral_max.py`):
FFT + точная проекция Лере + 2/3-деалиасинг + RK4; сходимость
N=32/48/64 до 10⁻¹³. Баланс энергии `dE/dt = −2νΩ` выполнен с
относительной ошибкой 4.3·10⁻⁵; дивергенция 10⁻¹⁷.

## 4. Кросс-верификация: вердикт «лягут ли друг на друга?»

**ДА — на трёх уровнях из четырёх:**

1. **Законы** (точно): диссипация `dE/dt = −2νΩ` (эталон) ↔ `dℋ/dt = −ν⟨Ω,LΩ⟩`
   (теорема); жёсткие ограничения div v = 0 ↔ Казимир-орбиты; точные
   константы: π³ = 31.006277 ↔ константа 4 МакВини. Буквальное
   пересечение: модуль `water.rs` движка (Ламб–Озеен `r² = r₀² + 8νt`) —
   это 2D-ступень каскада редукции §5 препринта.
2. **Траектории** (численно): энергия решателя лежит на истине NSE с
   +0.028% (T=0.4) и до +0.09% (128³, T=2.0); растяжение вихря поймано:
   рост энстрофии +36.8% против истинных +37.0%.
3. **Структура ошибки** (глубже всего): начальная энстрофия решателя
   воспроизводит **аналитический спектр центральных разностей** —
   `Ω_user(0)/Ω_ref(0) = sinc²(2π/N)` на всех сетках с точностью **5·10⁻⁹**:

   | N | измерено | sinc²(2π/N) | ошибка |
   |---|---|---|---|
   | 32 | 0.9872148 | 0.9872148 | 4.8·10⁻⁹ |
   | 64 | 0.9967914 | 0.9967914 | 5.1·10⁻⁹ |
   | 96 | 0.9985729 | 0.9985729 | 1.8·10⁻⁹ |
   | 128 | 0.9991971 | 0.9991971 | 2.2·10⁻⁹ |

4. **Формальные доказательства** — НЕ лягут (честно): Lean-файл в
   poler-engine — заглушка (`Idempotent P := True`); препринт строг, но
   не машинно-проверен. Ни один путь не закрывает Клэй формально —
   что совпадает с §7–8 препринта.

**MAX-LOAD** (`protocols/maxload_ns_comparison_output.txt`): 4 сетки
32³→128³ (2 097 152 узла), все до T=2.0, 1000 шагов, 3.28·10⁹
узло-обновлений; blow-up НЕТ ни на одной сетке при полной фазе растяжения
вихря; энергия сходится монотонно (+0.271 → +0.026); дивергенция ПАДАЕТ
с ростом сетки (8.65·10⁻⁴ → 7.05·10⁻⁵).

## 5. Расширение границы eigen (новая работа)

Полигон для вычислительных границ движка — собственные значения
`T_n = tridiag(2,−1,n)` (спектр `2−2cos(kπ/(n+1))`, детерминант `n+1`):

| Метод | n | Точность | Время |
|---|---|---|---|
| `eigen` (charpoly Фаддеева–Леврерье → Дюран–Кернер) | 16 | 4.3·10⁻⁷ | <1 c |
| `eigen` | 24 | 9.7·10⁻² (мнимые 9.3·10⁻²) | <1 c |
| `eigen` | 28 | **1.9·10⁶ — взрыв (Уилкинсон)** | <1 c |
| **Штурм-бисекция через калькулятор движка** | 128 | **4.55·10⁻¹³** | 5.5 c |
| **Штурм-бисекция** | 256 | **4.54·10⁻¹³** | 20 c |
| `det` (LU, частичный выбор ведущего) | 128 | 2.7·10⁻¹² (det = 129.0000000000027) | 6 мс |

Взрыв `eigen ≥ 28` — комбинаторный рост коэффициентов характеристического
полинома (феномен Уилкинсона): **алгоритмический предел, не предел
вычислителя**. Граница расширена с n ≤ 24 до **n = 256** (×10.7) БЕЗ
изменения движка — та же арифметика калькулятора (переменные, `+`, `*`,
`sign`) в структурно-осознанном алгоритме: последовательность Штурма
ведущих миноров `d_k = (2−x)d_{k−1} − d_{k−2}` + бисекция по монотонности
счёта `N(x)`. Всё считает сам калькулятор (`eigen-boundary/sturm_eigen_engine.py`
генерирует только текст REPL-скрипта). `prod(λ) = 257.000000 = det(T₂₅₆)` —
спектр и детерминант сошлись с двух сторон.

Тот же урок, что и в задаче Навье–Стокс: **структура бьёт грубую силу** —
осознанный алгоритм на «слабой» арифметике оказывается точнее грубого
алгоритма на той же арифметике.

### 5.1 Квантовый слой движка (`quantum`)

- Формальная верификация унитарности QFT: **U†U = I, невязка 2.22·10⁻¹⁶**
  (машинный эпсилон), норма случайных состояний 6.66·10⁻¹⁶;
- телепортация на **точном кольце ℤ[1/√2, i]**: фиделити = 1 точно,
  расхождение веток 0 — структурное равенство амплитуд, не приближение;
- Гровер n=10: метка 42 найдена с p = 0.999 за 25 итераций (560 вентилей);
- граница симуляции на данном хосте (3 ГБ RAM): **24 кубита**
  (вектор состояний 2²⁴ × 16 Б = 268 МБ; n ≥ 26 — OOM).

QFT — это собственно квантовый путь к собственным значениям (фазовая
оценка читает спектр унитария через обратное QFT): симулятор исполняет
его точно, реальному квантовому ПК понадобилась бы полиномиальная
память вместо экспоненциальной. «Квантовая вычислимость» здесь —
честная симуляция с формально проверенной унитарностью.

### 5.2 Внутренняя нейросеть движка (triune)

Динамика нейронной популяции (`src/triune/neuron.rs`) живёт на том же
роторе, что и редукция Навье–Стокс:

```text
a_j(t+1) = λ·a_j + γ·[(1−β)·W + β·J]·a_i,   J = (W − Wᵀ)/2
dp/dt = −η·(D·p + γ·J·p)                     — каноническое уравнение POLER
```

Антисимметричный ротор J (анти-луп) + диссипация λ < 1 — та же
геометрия «𝔰𝔬(3)-подобное вращение + вязкость», что гарантирует
отсутствие blow-up в §6 препринта. Живая проверка (авто-эволюция 30 с,
47 циклов, STDP): критичность 0.54–0.57 (субкритический коридор),
синапсы +0.246% (Хебб, не лавина), дофамин 0.82–0.90 — **взрыва нет
на всём горизонте**. Сертификат Ляпунова работает в кремнии.

Что нейросеть НЕ делает: не чинит Уилкинсона. Никакая адаптивная
вычислительная мощность не сделает коэффициенты charpoly представимыми
в f64 — это структурный факт. Границу расширяет алгоритм (Штурм),
а нейросеть живёт на той же геометрии, что и теорема об отсутствии
blow-up. Одна конструкция — три воплощения.

## 6. Честные границы (что НЕ закрыто)

- Задача Клэя **формально не закрыта ни одним путём**: сферические
  орбиты SO(3) не содержат растяжения вихря — полная 3D редукция
  требует несферических орбит (открытая проблема, §7–8 препринта);
- Lean-доказательства отсутствуют (файл-заглушка в poler-engine);
- «машинная точность» дивергенции решателя — фактически 10⁻⁴..10⁻⁵
  (12 итераций Якоби); спектральная проекция даёт 10⁻¹⁷;
- плато ошибки Эйлера +0.0035 (не зависит от сетки) — RK2/RK4 снесёт
  до ~10⁻⁶;
- `eigen` для плотных матриц n ≥ 28 в самом движке требует замены
  charpoly-пути на QR-итерацию/Ланцоша (см. §5: обход уже показан).

## 7. Воспроизведение

```bash
# Путь II: решатель (Rust, только std)
rustc -O solvers/bench_navier_stokes_clay_max.rs -o clay_bench
./clay_bench 32 200 0.002 10    # N, шаги, dt, период вывода

# Спектральный эталон (numpy)
python3 solvers/ns_spectral_max.py

# Путь I: 23 проверки редукции
python3 verification/verify_so3.py

# Граница eigen: Штурм через калькулятор poler-engine v0.61.0
python3 eigen-boundary/sturm_eigen_engine.py 128
python3 eigen-boundary/sturm_eigen_engine.py 256

# Квантовый слой
poler-engine --exec 'quantum verify unitary qft --n 4'
poler-engine --exec 'quantum teleport --exact'

# Нейросеть
poler-engine --triune-auto-evolve 30
```
